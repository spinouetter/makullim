## 정리 (작성: Claude)

빌리 엘리엇 2026 시즌이 7/26 저녁 공연으로 막을 내렸다. 회차 종료 판정(`isEnded`)은 지금까지 "공연 시작 + 러닝타임 경과" 시간 룰뿐이라, 막공 직후에는 아직 '진행 중'으로 보였다. 공연 정의에 **시즌 종료 플래그**를 추가하고, 종료된 공연은 시간 룰과 무관하게 모든 회차를 완료로 처리한다(데이터 주도 — 다른 공연에도 그대로 적용 가능).

## 결정 사항 (작성: Claude)

- 플래그는 회차별이 아니라 **공연 정의 레벨**(`ended`) — 시즌 종료는 공연의 속성이고, 새 공연 추가 시 코드 수정이 없다.
- `isEnded`는 통계·도장(isPickable 경유)·막공·티켓 '지난 공연' 분류 등에서 두루 쓰이므로, 이 한 곳만 고치면 "종료된 공연 = 전부 완료"가 앱 전체에 일관 적용된다.
- `endDate`로 자동 추론하지 않고 명시 플래그를 쓴 이유: 막공 당일(마지막 회차 종료 전)에도 즉시 완료 처리하고 싶다는 요청이라, 날짜 기반 자동 판정과 어긋난다.
