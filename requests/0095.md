# 요청 #0095 — Finale 관극수 0을 빈칸 대신 "0"으로 (관극 기록이 전혀 없을 때만 빈칸)

상태: 완료

---

## 요청 (작성: Spinouetter)

<!-- 대화로 요청됨 -->

- finale에서 숫자를 안 채우는 건 공연을 단 한 번도 안 봤을 때야. 그게 아니면 0 적어줘.

---

## 정리 (작성: Claude)

Finale 보드의 관극수 분자(`setCount`)는 값이 0이면 항상 투명 "00"으로 자리만 잡았다(공유받은 사람이 손글씨로 채우는 용도). 그러다 보니 관극 기록이 있는 사용자의 보드에서도 안 본 배우 칸이 빈칸으로 남았다. → **빈칸은 관극 기록이 하나도 없는 사용자(=공유받은 사람)일 때만**, 관극이 있으면 0도 그대로 표기한다.

## 할 일 (작성: Claude)

- [x] `js/finale.js`: `anyWatch()` 헬퍼(관극 기록 존재 여부, `isEnded && hasSeat`) 추가, `setCount`의 `blank` 조건을 `!w` → `!w && !anyWatch()`로 변경. finale.js v89.

## 결정 사항 (작성: Claude)

- 판정은 회차 데이터 전수(`performanceData.performances`) 기준 — 손글씨 빈칸 용도(공유용)는 그대로 살아 있다.
- 관극수 0 배우의 **셀 자체를 숨기는** 보드(woojin 정산판, 0090)는 별개 로직으로 영향 없음.
