## 정리 (작성: Claude)

Finale 탭의 통계 기준(`finaleModeSelect`)은 **저장되지 않고 있었다** — finale.js의 `finaleMode`는 탭을 처음 열 때 Statistics 탭의 저장값(`castStatsMode`)을 1회 복사해 초기화했고, 이후 변경은 메모리에만 남아 리로드하면 사라졌다.

이를 **독립 설정으로 저장**한다: app.js 상태 스냅숏(localStorage `makollim:state:v1:<id>`, Dropbox 백업 대상)에 `finaleStatsMode` 키를 추가하고, finale.js가 탭 첫 진입 시 복원·변경 시 즉시 `saveState()`로 저장한다. 더 이상 Statistics 탭 값을 상속하지 않으며 **기본값은 `all`(공연 중 배역 변경 반영)**.

## 할 일 (작성: Claude)

- [x] app.js: `finaleStatsMode`(기본 `"all"`) 전역 + `buildStateSnapshot()`/`loadStateFromStorage()`에 저장·복원 추가
- [x] finale.js: 첫 진입 동기화를 `castStatsMode` 상속 → `finaleStatsMode` 복원으로 교체. 저장값이 현재 셀렉트 옵션에 없으면(예: 제거된 `first`) `all`로 폴백
- [x] finale.js: `finaleModeSelect` change 시 `finaleStatsMode` 갱신 + `saveState()` 즉시 저장
- [x] 캐시 버전: app.js v213 · finale.js v86
- [x] 검증(Playwright): 기본값 `all` → `weighted` 변경 → localStorage `finaleStatsMode:"weighted"` 저장 → 리로드 후 셀렉트가 `weighted` 유지

## 결정 사항 (작성: Claude)

- **별도 localStorage 키가 아니라 app.js 상태 블롭에 통합** — 이 저장소의 설정은 전부 상태 스냅숏 한 덩어리로 저장·Dropbox 백업되므로, 같은 경로에 넣어야 백업·복원이 함께 된다.
- **Statistics 탭 상속 제거**: 기존 '첫 진입 시 castStatsMode 복사'는 저장 도입과 충돌(복원값을 덮음)하므로 제거. 두 탭의 통계 기준은 이제 완전히 독립.
- **폴백**: 셀렉트에서 `first`(최초 캐스트)가 제거된 상태라, 과거 저장값이 옵션에 없으면 기본값 `all`로 되돌린다.
